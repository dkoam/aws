HardcoreRevive (Paper 26.3 / Java 25)

빌드:  mvn package   ->  target/HardcoreRevive-1.0.0.jar  를 서버 plugins/ 폴더에 넣고 재시작
주의:  기존 데이터팩(revive_bandage)은 월드의 datapacks 폴더에서 지우세요. (붕대 아이템이 서로 달라서 같이 쓰면 안 됩니다)

조합법: 가운데 다이아몬드 + 둘레 8칸 네더라이트 파편 -> 부활 붕대(종이)
사용:   붕대를 들고 우클릭 또는 F키 -> 죽은 사람 명단 -> 머리 클릭
자가부활: 붕대가 인벤토리(왼손 포함)에 있으면 치명타를 맞을 때 자동으로 살아남 (토템처럼)
명령어(OP): /부활 <이름> /부활 목록 /부활 전체 /부활붕대 [이름]
